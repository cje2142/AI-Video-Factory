# AI Video Factory Rules v1.0

## 프로젝트 목표
n8n을 중심으로 AI Shorts 제작 공장을 구축한다.

## 역할 분담
- ChatGPT: 프로젝트 기획, 구조 설계, 단계별 진행, 검증 총괄
- Gemini: n8n/ComfyUI 개발, 수정, 품질 검수
- 사용자: 실행, 테스트, 결과 확인

## 개발 원칙
1. 한 번에 한 단계만 수정한다.
2. 정상 동작하는 워크플로우는 즉시 변경하지 않는다.
3. 모든 수정은 검증 후 다음 단계로 진행한다.
4. 코드 수정 시 항상 전체 수정본을 사용한다.
5. 개발자가 아닌 사용자 기준으로 설명한다.

## 현재 검증 완료
- Ollama 연동 성공
- Qwen 스크립트 생성 성공
- n8n 동작 확인
- ComfyUI API 연동 성공
- PNG 이미지 생성 성공
- ComfyUI → n8n Binary 전달 성공
- Windows 파일 저장 성공
- MP4 생성 성공

## 목표 파이프라인
주제 생성
→ 대본 생성
→ Scene 분리
→ 이미지 프롬프트 생성
→ 이미지 생성
→ 영상 생성
→ 나레이션 생성
→ 자막 생성
→ BGM 생성
→ 최종 합성
→ Shorts MP4 출력

## 운영 규칙
- 단계별 실제 파일 생성 확인
- 실패 시 이전 정상 버전으로 복귀
- GitHub를 공식 백업 저장소로 사용
- 모든 주요 변경사항은 문서화
